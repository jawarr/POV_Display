# POV_Display
Final project for Embedded Systems II <br>
Persistence of vision display using STM32F446RE microcontroller, with built in temperature sensing and real time. <br>
![Alt text](POV_Display/schematic.png "Complete electrical schematic for POV display") <br>
Instructions:
1)  Configure a putty terminal for the correct COM port with 115200 BAUD
2)  To display words, type any string of your choice (18 characters max)
4) To display temperature, enter "temperature" with desired unit ('f' or 'c')
6) To display clock, enter "clock" with current time (for example, "10 52")
